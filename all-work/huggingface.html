Hugging Face Hub

Same-Bucket File Copy Support in HfFileSystem

I contributed same-bucket file copy support to Hugging Face Hub's HfFileSystem. The change enables supported file operations within Hugging Face Storage Buckets, including server-side copies by hash for Xet-backed files.

An Official Feature in v2.4.0

PR #5080 was merged and released in huggingface_hub v2.4.0. Same-bucket copy also enables supported mv and rename workflows through copy-then-delete behavior.

The implementation includes end-to-end coverage for copy, move, rename, and unsupported paths. Cross-bucket and bucket-to-repository copies remain unsupported.
